C covers applicants whose primary need is finding work or working remotely. The tier is RAG-decided: most C cases land on Tier 3 (job search workload — applications, video interviews, resumes) but applicants whose target role requires specific desktop software may justify Tier 2.

## Tier guidance for C

- **Job-searching only** (applying, interviewing, resume building): T3. The full job-search workload — Indeed, LinkedIn, government job boards, Zoom interviews, Word/Docs resume — is browser- and document-driven.
- **Already-employed remote worker requiring specific software**: bump to T2 if the role's required tools (e.g., a CRM client, design software for a contractor, Microsoft 365 Desktop) exceed T3 capability.
- **Trades or skill development**: T3, with T2 acceptable if the applicant is enrolled in a digital trades program (e.g., AutoCAD intro, accounting software).

## Tier rationale

C applications receive the priority bump (`+0.05` from the scoring layer) because employment is time-sensitive — every week of unemployment compounds. Within C, however, the inventory should match the workload: handing out a T1 to someone job-searching wastes hardware on a workload it doesn't need.

## Edge cases

- An applicant transitioning into a tech career and learning to code: the case for T2 (versus T3) strengthens if VS Code with extensions is part of the daily workflow.
- An applicant who needs a device specifically to enroll in a job-training program: cross-reference the program's tech requirements before choosing a tier.
